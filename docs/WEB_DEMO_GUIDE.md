## 🎯 功能介绍

### 1. 🖼️ 样本可视化
- **功能**: 查看单个样本的详细信息
- **使用方法**:
  1. 点击"🚀 加载数据集"按钮
  2. 在"样本ID"输入框中输入0-102349之间的数字
  3. 点击"🔍 可视化样本"按钮
  4. 查看左图（边界框）和右图（分割掩码）
- **快速按钮**:
  - "随机样本": 随机选择一个样本
  - "样本0": 跳转到样本0
  - "样本100": 跳转到样本100
  - "样本1000": 跳转到样本1000

### 2. 📊 数据集统计
- **功能**: 查看数据集的整体统计信息
- **包含内容**:
  - 总样本数量
  - 问题数量分布
  - 图像尺寸统计
  - 类别分布（前20个最常见类别）
- **使用方法**: 点击"📈 获取统计信息"按钮

### 3. 🚀 DataLoader测试
- **功能**: 测试PyTorch DataLoader的批处理功能
- **参数设置**:
  - 批次大小: 1-8（推荐2-4）
  - 测试批次数: 1-10（推荐3-5）
- **显示信息**:
  - 批次配置详情
  - 每个批次的张量形状
  - 样本路径示例
- **使用方法**: 设置参数后点击"🧪 测试DataLoader"按钮

### 4. 🎲 随机浏览
- **功能**: 随机选择多个样本进行可视化
- **参数**: 浏览样本数（1-5个）
- **输出**: 图片画廊和详细信息
- **使用方法**: 设置样本数后点击"🎲 随机浏览"按钮

## 🔧 故障排除

### 常见问题

**问题1**: 数据集加载失败
- **原因**: 数据集路径不正确或权限问题
- **解决**: 检查 `../dataset_sesame` 路径是否存在

**问题2**: 图像显示不出来
- **原因**: 图像路径问题或图像文件损坏
- **解决**: 尝试其他样本ID

**问题3**: 内存不足
- **原因**: 批次大小设置过大
- **解决**: 减小批次大小到1-2

**问题4**: 网页无法访问
- **原因**: 端口被占用或防火墙阻止
- **解决**: 检查端口7860是否开放

### 性能优化建议
- **批次大小**: 建议设置为2-4以平衡性能和内存使用
- **浏览样本数**: 建议设置为3-5个以获得最佳体验
- **网络环境**: 在本地网络环境下使用以获得最佳响应速度
